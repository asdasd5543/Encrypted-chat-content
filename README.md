# 私钥/公钥文本加解密工具

这是一个单文件 Python 命令行工具，使用 RSA 公钥加密、RSA 私钥解密。程序通过 RSA-OAEP-SHA256 加密 AES 密钥，再使用 AES-256-GCM 加密文本；GCM 也会验证密文是否被篡改。

## 功能

- 生成 RSA 密钥对，并用密码保护私钥。
- 选择公钥加密文本，生成加密文件。
- 选择私钥解密加密文件，并在终端显示结果。
- 通过粘贴路径或文件选择窗口选择密钥和加密文件；在路径提示处直接回车、输入半角 `?` 或全角 `？` 可打开选择窗口。
- 支持 PEM、DER、OpenSSH RSA 密钥；`.asc` 密钥文件使用本工具的 PEM 文本内容。
- 加密结果可保存为 JSON 或本工具定义的 ASCII `.asc` 封装。

## 运行环境

- Windows、Python 3。
- `cryptography` Python 包。若当前环境没有该依赖，程序会询问是否为当前 Python 安装兼容版本；仅使用预编译 wheel，不会尝试本机源码编译。
- 加密 OpenSSH 私钥还需要 `bcrypt`。选择此格式时，程序会询问是否安装。

如果自动安装失败，可在终端中用运行脚本的同一个 Python 安装依赖：

```powershell
python -m pip install --user cryptography
```

如果还需要生成加密的 OpenSSH 私钥：

```powershell
python -m pip install --user bcrypt
```

然后运行：

```powershell
python .\secure_message_tool.py
```

双击运行时，程序结束后会等待按回车关闭窗口。若启动方式使用的是 free-threaded Python，且同一安装目录存在标准版 Python，程序会尝试切换到标准版运行。

## 使用步骤

### 生成密钥

1. 在菜单选择“生成私钥和公钥”。
2. 输入目录路径，或直接回车将密钥保存在当前目录；输入 `?` 或 `？` 可浏览选择目录。
3. 选择密钥格式并设置私钥密码。
4. 将公钥文件交给需要向你发送加密信息的人；私钥和密码只由你自己保管。

### 加密信息

1. 选择“使用公钥加密文本”。
2. 粘贴 RSA 公钥文件路径；直接回车或输入 `?`、`？` 可浏览选择。
3. 输入文本、选择 JSON 或 ASCII `.asc` 加密结果格式，再选择保存位置。
4. 将加密文件交给持有相应私钥的人。

### 解密信息

1. 选择“使用私钥解密文件”。
2. 选择私钥文件并输入该私钥的密码。
3. 选择 JSON 或本工具的 ASCII `.asc` 加密文件。
4. 解密后的文本会显示在终端中。注意周围环境和终端历史记录，避免让他人看到敏感内容。

## 密钥与格式说明

- **公钥可以分享，私钥不能分享。** 不要通过聊天、邮件或代码仓库发送私钥或私钥密码。
- 第一次接收他人的公钥时，应通过电话、当面等独立渠道核对指纹，降低公钥被替换的风险。本工具目前不提供指纹校验界面。
- `.asc` 只是文件扩展名。本工具的 `.asc` 密钥和加密文件都是本工具定义/保存的文本格式，**不是 GPG/OpenPGP 格式**，不能据此认为它与 GPG 或其他 OpenPGP 软件互通。
- OpenSSH 格式适用于 RSA 密钥；其他软件对密钥算法、封装和加密方式的支持可能不同。跨软件使用前先用测试文本验证兼容性。
- JSON 和 ASCII `.asc` 加密文件包含密文，不包含解密私钥。密文仍建议只交给预期接收者。
- RSA 与 AES 的组合保护的是信息机密性和完整性；该工具不会验证发送者身份，也不提供数字签名。
